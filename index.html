📊 claude-code-statusline - Monitor your Claude Code session stats

Download Latest Version

The claude-code-statusline tool provides a visual status bar for your Claude Code sessions. It displays your token usage, session costs, and rate limit countdowns directly in your terminal. This tool helps you manage your usage and stay within your limits while you work.

✨ Key Features

  • Shows your context window usage with a color bar.
  • Tacks your live session cost in real time.
  • Displays token usage updates.
  • Lists accurate countdowns for 5-hour and 7-day rate limits.
  • Provides simple hints for your next steps.
  • Works without additional software dependencies.

📥 Download and Installation

Follow these steps to set up the status line on your Windows computer.

  1. Visit the releases page to find the latest version.
  2. Download the zip file for your system.
  3. Extract the contents of the folder to a location you can easily find, such as your Documents or Downloads folder.
  4. Open your PowerShell or Bash terminal.
  5. Run the execution script included in the folder.

⚙️ System Requirements

This tool runs on Windows, macOS, and Linux. You need a terminal application like PowerShell or Bash available on your computer. The tool requires no extra programs or compilers to function. It uses minimal system memory and keeps your computer speed fast during sessions.

📈 Monitoring Your Usage

Once you start the tool, you will see a bar at the bottom of your terminal window. This bar updates when new information becomes available. If you reach a limit, the bar changes color to warn you. The reset times for your limits show up clearly, helping you plan your work intervals effectively.

🛠 Troubleshooting

If the bar does not appear, check that your terminal window supports high-color text. Most modern Windows terminals work without changes. Ensure you have the permissions needed to run scripts in your terminal. If you see an error message, try restarting your terminal window to refresh the session.
